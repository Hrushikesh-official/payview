# payview

Smart QR Payment Display System

PayView is an ESP32-based smart payment display designed for merchants. The device displays QR payment information, transaction status, sales statistics, and merchant analytics in a compact and affordable form factor.

Features

* QR code display
* Real-time payment notifications
* Daily sales tracking
* Transaction history
* Wi-Fi connectivity
* Merchant dashboard
* Low-cost ESP32 hardware

Hardware

* ESP32
* TFT Display
* Wi-Fi Module (built into ESP32)
* Optional Speaker/Buzzer
* Optional Battery Backup

Software Stack

* C++
* Arduino Framework
* GitHub
* ESP32 Libraries

Project Goals

* Reduce merchant payment confusion
* Provide instant payment confirmation
* Track business performance
* Create an affordable smart payment solution
