PayView Project Plan

Goal

Build a smart QR payment display device for merchants using ESP32.

Problem

Current payment sound boxes only announce payments. They do not provide a visual dashboard showing transaction history and business statistics.

Solution

Create a smart display that:

* Shows QR payment information
* Displays recent transactions
* Shows daily sales totals
* Connects to Wi-Fi
* Provides a simple merchant dashboard

Hardware Components

* ESP32
* TFT Display
* Speaker/Buzzer
* Power Supply

Software

* C++
* Arduino Framework
